# Personnages

Déposer ici le modèle de Loums exporté de Meshy, sous le nom **`loums.glb`**
(format GLB, squelette Mixamo, animations incluses : attente, marche, course).

Le jeu le charge tout seul au lancement et remplace la capsule orange.
Sans fichier, la capsule reste.

Ces fichiers ne sont **pas** envoyés sur GitHub (dépôt public, licence privée).
